
# SMC Trading Pro

منصة عربية لتحليل الأسواق ومتابعة إشارات تداول الذهب والفضة.

## الأسواق المدعومة

- XAUUSD — الذهب
- XAGUSD — الفضة

## مكونات المشروع

- `app/` — لوحة التحكم العربية وتطبيق PWA.
- `server/server.js` — خادم API واستقبال الطلبات.
- `tradingview/` — ملفات Pine Script الاختيارية.
- `package.json` — إعداد تشغيل الخادم.
- `.env.example` — نموذج متغيرات البيئة.

## المميزات المستهدفة

- عرض أسعار الذهب والفضة.
- تحليل اتجاه السوق: صاعد أو هابط أو متذبذب.
- مناطق الشراء والبيع.
- إشارات الدخول.
- الهدف الأول TP1 والهدف الثاني TP2.
- وقف الخسارة SL.
- سجل الإشارات.
- إرسال التنبيهات إلى Telegram.
- واجهة عربية قابلة للتثبيت على الهاتف.

## تشغيل الخادم محلياً

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm start
```

سيعمل الخادم على المنفذ المحدد في متغير PORT.

## متغيرات البيئة

أضف المتغيرات التالية في إعدادات استضافة الخادم:

- `PORT`
- `WEBHOOK_SECRET`
- `BIQUOTE_API_URL`
- `BIQUOTE_API_KEY`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

لا تضع المفاتيح السرية داخل ملفات GitHub العامة.

## واجهات API الحالية

- `GET /api/status`
- `GET /api/markets`
- `GET /api/analysis`
- `GET /api/signals?limit=20`
- `POST /api/telegram/test`

## مصدر البيانات

المصدر المعتمد للمشروع هو BiQuote.

يجب التحقق من عنوان API الرسمي وطريقة المصادقة وبنية بيانات الأسعار قبل اعتماد عرض الأسعار الحقيقية.

## حالة التطوير

المشروع قيد التطوير والاختبار.

ملف الخادم الحالي يوفر الهيكل الأساسي للواجهات، ولا يعني ذلك أن محرك التحليل أو تكامل BiQuote أو إرسال إشارات التداول الحقيقية قد اكتمل.

يجب اختبار الأسعار والإشارات والتنبيهات قبل استخدام المنصة في التداول الفعلي.

## تنبيه المخاطر

إشارات التداول تحليلية وليست ضماناً للربح. التداول في الذهب والفضة ينطوي على مخاطر مالية، ويجب اختبار الاستراتيجية قبل استخدامها بأموال حقيقية.
